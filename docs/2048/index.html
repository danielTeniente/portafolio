Place the largest value at 1; aim for progressively smaller values along 2 → 16. Numbers show preferred positions, not tile values.

Board quality Φ combines 40% corner anchoring, 30% descending snake order, 20% empty space, and 10% adjacent equal pairs. It is bounded between 0 and 1. We fixed these weights before the run and did not tune them against the results.

Bonus = 0.99 × Φ(next board) − Φ(current board)

The next board includes the random spawn. Terminal potential is zero; a time-limit cutoff is not terminal. The bonus can be negative, even on a scoring move. It is a learning signal, not additional game points.

The Q-table still sees only largest tile and empty count. Shaping is calculated from the full environment board, but no new features are added to its state. It therefore cannot distinguish all arrangements that the strategy rewards. Potential-based shaping does not guarantee faster learning or improvement within a finite budget.

03 / WHAT IS ACTUALLY LEARNING?

One Bellman target. Three approximations.

Stage 1: R = r / 128
Stage 2: R = r / 128 + [0.99 Φ(s′) − Φ(s)]
y = R + 0.99 × max Q(next state, legal next action)
Terminal state: Φ(s′) = 0 and y = R
Q-table: Q(s,a) ← Q(s,a) + 0.1 × [y − Q(s,a)]

Tabular Q-learning

(largest tile, empty cells) → 4 Q-values

Only these two quantities form the table key. Legal actions are supplied by the environment. Different boards can share a row, so the observation is lossy and standard Markov-state convergence guarantees do not apply.

Dense DQN

16 → Dense 64 → ReLU → Dense 64 → ReLU → 4

Every input is a tile exponent divided by 16, with 0 for empty. The network shares learned weights across boards and returns four action values. No one-hot encoding.

CNN-DQN

1 × 4 × 4 → Conv 16 (2 × 2) → ReLU → Conv 32 (2 × 2) → ReLU → Flatten 128 → Dense 64 → ReLU → 4

The same 16 scaled exponents retain their row and column positions. Both convolutions use stride 1 and no padding. Spatial filters share weights; the final layers use the whole board. No pooling or one-hot channels.

Both DQNs use Adam (learning rate 0.0005), Huber loss, a 10,000-transition replay buffer, 64-sample minibatches, a 256-transition warmup, one update every 4 moves, and a separate target network copied every 250 updates. Gradient norm is clipped at 10. Only legal next actions contribute to the target. This is standard DQN, not Double DQN.

Within each stage, all three use the same reward. Stage 1 uses raw merge points divided by 128. Stage 2 adds the potential-based corner-and-snake term. Exploration decreases linearly from ε = 1 to 0.05 across training episodes. Evaluation uses ε = 0, with seeded random tie-breaking. Experiments cap games at 2,000 moves; truncations are reported and are not treated as terminal in learning targets. Human play has no cap.

05 / THE ENVIRONMENT CONTRACT
Rules we can agree on.
01
Start with two tiles
A 4 × 4 board begins with two randomly positioned tiles. Each new tile is 2 with probability 90%, or 4 with probability 10%. Empty positions are equally likely.
02
Move the whole board
Choose up, right, down or left. Tiles slide as far as possible. Equal neighbors merge in the direction of movement. A tile can merge only once per move.
[2, 2, 2, 2] → [4, 4, 0, 0]Example: move the left-hand row left to get the right-hand row.
03
Reward the merges
Merging 2 + 2 creates 4 and earns 4 points. Two such merges earn 8. Sliding without merging earns 0. A valid move spawns exactly one tile afterward.
04
Know when to stop
Reaching 2048 is a milestone; play continues. The episode ends only when no direction changes the board. Invalid moves leave the board, score and random sequence unchanged.
Shared learning contract: expose only legal actions and scale merge reward by 1/128 for all agents. Stage 2 adds a board-quality potential difference; neither stage adds an invalid-move penalty. Human play has no move limit; the training experiment reports cutoffs at 2,000 moves.


06 / CHOOSE WHAT A STATE MEANS
Same board. Different descriptions.
A state should contain enough information to determine which transitions are possible. Keeping every tile’s position preserves that information; reducing the board to a few statistics can lose it.
Positions are ordered row by row, from the top left. Switching this view does not change the game or commit us to a model.
LIVE STATE / CURRENT BOARD
What belongs outside the state?
Score and move count are reporting metadata: they do not change legal moves or future rewards. The seed is for reproducing experiments, not a future agent input. Under the intended independent tile-spawn model, the complete board is a Markov state. A seeded simulator also retains an internal pseudorandom-generator state for reproducibility.
How these representations relate to the agents
Tile values and exponents are lossless descriptions of the same state space. Exponents make the numbers smaller but do not reduce the number of distinct boards a Q-table must store. A table would need a consistent key for all 16 cells.
The Q-table uses only largest tile and empty-cell count. Both neural networks receive tile exponents divided by 16; the CNN retains the 4 × 4 spatial layout. None of the agents uses one-hot encoding. The extended summary shown here is for inspection and is not the Q-table key.
The summary reports empty cells, largest tile, total tile value and legal actions. Different arrangements can share these statistics and still produce different next boards and rewards. It is an intentionally lossy observation, not an equivalent Markov state.
